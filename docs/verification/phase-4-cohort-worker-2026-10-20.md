# Phase 4 installed-cohort worker candidate — 2026-10-20

The main one-shot document worker now reads a fixed `/opt/localai/documents/cohort.json` manifest when present. Its grammar permits only a bounded version-1 set of local `/opt/localai/` roots; on Linux the manifest and every parent must be root-owned, with no group/other write permission and no symlink at the manifest path. No request can supply an executable, model or manifest path. An absent manifest keeps the text-only worker behavior; a malformed present manifest stops worker startup. The source adds no production manifest or package installation.

The disposable Debian proof first failed against the old main worker with `document_worker_invalid_frame` on a mixed PDF. After wiring the cohort factory, a temporary root-owned manifest pointed only to the existing candidate dependencies. The same main worker completed the encrypted mixed-PDF job through its restricted transient systemd unit and deleted the result. The temporary manifest was removed. The no-manifest text and active-cancellation native proof also passed. Windows full suite: 244 passed, 7 Linux-only skips, zero failures. Debian full suite: 251 passed, zero skips or failures. Documentation checks pass. The enrolled gateway retained PID 19963 and no document units remained.

This is source and candidate runtime wiring, not a qualified installed cohort. An installer-generated exact version/license/hash manifest, dependency byte verification, coordinated activation/rollback and sustained joint-load gates remain necessary before production can use rich processing. Public document routes are still disabled.
