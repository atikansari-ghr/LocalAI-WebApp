# Phase 4 persistent supervisor resource gate candidate — 2026-10-20

The inactive root document supervisor now prepares native-unit recovery before opening its private socket. Its scheduling loop uses the aggregate resource reader to postpone a queued claim when measured memory headroom, swap or pressure is unsafe. After admission, the same gate monitors pressure and passes an abort signal into the job runner. The runner records cancellation, waits for verified native unit cleanup and then settles the encrypted claim. If a launch fails without cleanup confirmation, it performs native recovery before returning, so the next admission cannot overtake an unresolved claim.
