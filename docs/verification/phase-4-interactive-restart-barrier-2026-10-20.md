# Phase 4 interrupted interactive lease barrier — 2026-10-20

The inactive supervisor candidate now writes and synchronizes a root-owned marker before granting a chat lease. The gateway-side candidate waits for its inference call to settle, sends an explicit completion frame and waits for a release acknowledgement. Only that completion clears and synchronizes the marker. A disconnect, supervisor failure, malformed release or incomplete handshake leaves the marker in place. On startup and before each background claim, the supervisor checks it and refuses document work while it remains. This prevents a restarted supervisor from launching a document worker merely because its in-memory admission queue was lost while chat might still be running.

RED→GREEN tests cover an interrupted granted lease surviving a fresh barrier instance, a clean completion or settled inference error removing its marker, wrong-token refusal and a scheduler that never claims while recovery is required.
