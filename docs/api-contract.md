# Planned document API contract

The phase-4 [OpenAPI document](openapi-documents.json) uses [OpenAPI 3.1.2](https://spec.openapis.org/oas/v3.1) and describes planned operations only. The deployed phase-3 gateway still returns 404 for these paths. Do not publish the draft as an available API or include it in a public playground until the native supervisor, authorization, cleanup and whole-phase gates pass.

`POST /v1/ocr` and `POST /v1/extract` take one bounded base64 document with declared name/MIME, access scope, language/OCR mode and an idempotency key. The server independently checks decoded size, extension, MIME, magic and structure before storing a temporary encrypted job. A successful admission returns 202 with an opaque ID and expiry. Replaying the same key under the same principal/scope/operation/payload returns the same job; reusing it with different content returns 409. A submitted document is never fetched from a caller URL or filesystem path.

`GET /v1/documents/{id}/status` checks `document:read` and the submitting app/user namespace and scope before returning state and, on completion, reviewable source evidence. Inaccessible and absent IDs both return 404. `DELETE /v1/documents/{id}` checks `document:delete`, requests cancellation, waits for native cleanup and removes retained data. A still-active cancellation returns 202; verified deletion returns 204. Uploads are temporary by default with expiry; successful results and derived artifacts must be removed according to the selected retention policy. A future explicit save operation must be separate.

Browser mutations require an active secure session, exact HTTPS Origin and CSRF token. Bearer clients use independently scoped capabilities, approved IP networks and no browser cookie. Every request revalidates key/session, owner and scope, including status reads and deletion. Queue admission may return 429 or 503 without executing a parser. The internal encrypted job store is not yet wired to these routes, and its interrupted-job confirmation cannot be supplied by an HTTP caller.
